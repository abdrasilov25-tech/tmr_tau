# Как убрать ошибку «Не удалось удалить чат»

Сделай по шагам.

---

## Шаг 1. Открой Supabase

Зайди в [supabase.com](https://supabase.com) → свой проект.

---

## Шаг 2. Проверь таблицу `messages`

1. Слева открой **Table Editor**.
2. Выбери таблицу **`messages`**.
3. Убедись, что есть колонки: `id`, `sender_id`, `receiver_id`, `text`, `created_at`.
4. Над таблицей нажми **RLS** (или в настройках таблицы) — RLS должен быть **включён**.

---

## Шаг 3. Выполни SQL (политики и функция)

1. Слева открой **SQL Editor**.
2. Нажми **New query**.
3. Скопируй и вставь **весь** код ниже.
4. Нажми **Run** (или Ctrl+Enter).
5. Внизу должно быть зелёное сообщение об успехе, без красных ошибок.

```sql
-- Политики для messages
alter table public.messages enable row level security;

drop policy if exists "Messages select own" on public.messages;
create policy "Messages select own" on public.messages
  for select using (auth.uid() = sender_id or auth.uid() = receiver_id);

drop policy if exists "Messages insert own" on public.messages;
create policy "Messages insert own" on public.messages
  for insert with check (auth.uid() = sender_id);

drop policy if exists "Messages delete own" on public.messages;
create policy "Messages delete own" on public.messages
  for delete using (auth.uid() = sender_id or auth.uid() = receiver_id);

-- Функция удаления чата (сначала удаляем старую)
drop function if exists public.delete_chat(uuid);

create or replace function public.delete_chat(peer_id uuid)
returns json
language plpgsql
security definer
set search_path = public
as $body$
begin
  delete from public.messages
  where (sender_id = auth.uid() and receiver_id = peer_id)
     or (sender_id = peer_id and receiver_id = auth.uid());
  return '{}'::json;
end;
$body$;

grant execute on function public.delete_chat(uuid) to authenticated;
grant execute on function public.delete_chat(uuid) to service_role;
```

---

## Шаг 4. Проверь, что функция создана

1. В Supabase слева открой **Database** → **Functions**.
2. В списке должна быть функция **`delete_chat`** с аргументом `peer_id` (uuid).

Если её нет — вернись к шагу 3 и выполни SQL ещё раз, посмотри, не появилась ли ошибка внизу.

---

## Шаг 5. Перезапусти приложение

В терминале:

```bash
flutter run
```

Или останови приложение и запусти снова.

---

## Шаг 6. Проверь удаление чата

1. В приложении открой **Мои чаты**.
2. Долгим нажатием по чату открой меню → **Удалить чат** (или кнопка ⋮ → Удалить чат).
3. Чат должен исчезнуть из списка **без** сообщения «Не удалось удалить чат».

---

## Если ошибка всё равно появляется

В коде приложения при ошибке теперь пишется лог в консоль. Запусти приложение из терминала (`flutter run`), снова нажми «Удалить чат» и посмотри вывод в терминале — там будет строка вида:

- `delete_chat RPC error: ...` — значит, RPC не сработал, приложение пробует удаление через таблицу.
- `_deleteChat error: ...` — полный текст ошибки от Supabase.

Скопируй эту строку и используй для отладки (или пришли текст ошибки, чтобы подсказать следующий шаг).
