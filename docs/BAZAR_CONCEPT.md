# Концепция мобильного маркетплейса «Базар»

## Видение продукта

**Базар** — маркетплейс, где покупатель листает товары как ленту в Instagram/TikTok и покупает за 3–4 шага, а продавец ведёт профиль как бренд-страницу: лента товаров, сторис, подписчики и простая загрузка товаров.

---

## 1. Структура приложения

### 1.1 Архитектура навигации

```
Bottom Navigation (5 пунктов)
├── Главная (Home)        — лента товаров / сторис
├── Поиск (Search)        — поиск + фильтры + категории
├── Добавить (Add)        — быстрая публикация товара (для продавцов)
├── Избранное (Favorites) — сохранённые товары и списки
└── Профиль (Profile)     — личный кабинет / профиль продавца
```

### 1.2 Роли пользователей

| Роль       | Режим входа | Доступные функции |
|-----------|-------------|-------------------|
| Гость     | без аккаунта | просмотр ленты, поиск; покупка/избранное — после регистрации |
| Покупатель| аккаунт     | лента, поиск, избранное, покупки, чат с продавцами, подписки |
| Продавец  | аккаунт + верификация | всё для покупателя + профиль продавца, публикация товаров, сторис, статистика |

### 1.3 Модули приложения

- **Feed** — лента товаров, сторис, тренды
- **Search & Discovery** — поиск, фильтры, категории, рекомендации
- **Product** — карточка товара, быстрая покупка, избранное
- **Seller Profile** — профиль продавца (лента, подписчики, описание)
- **Checkout** — корзина и оплата (3–4 шага)
- **Messaging** — чат покупатель ↔ продавец
- **User Profile** — настройки, заказы, избранное, подписки
- **Seller Dashboard** — добавление товара, статистика, сторис

## 2. Основные экраны

### 2.1 Для всех пользователей

| Экран           | Описание |
|-----------------|----------|
| **Главная (лента)** | Вертикальная/горизонтальная лента карточек товаров (формат сторис/Reels). Свайп вверх — следующий товар. Сверху — сторис продавцов. Блоки: «Тренды дня», «Популярное», «Рекомендуем». |
| **Поиск**       | Поле поиска, быстрые категории (чипы), фильтры (цена, категория, рейтинг продавца, доставка). Результаты — сетка карточек или список. |
| **Карточка товара** | Большое фото (свайп по фото), название, цена, кнопка «Купить» / «В корзину», описание, продавец (аватар + имя, переход в профиль), отзывы, рейтинг. |
| **Профиль продавца** | Аватар, имя, описание, счётчики (подписчики, товары), кнопка «Подписаться», лента товаров сеткой (как в Instagram). Опционально: вкладка «Сторис». |

### 2.2 Покупатель

| Экран           | Описание |
|-----------------|----------|
| **Избранное**   | Сохранённые товары (сетка). Папки/списки (например, «Подарки», «Дом»). |
| **Корзина**     | Список товаров, итог, кнопка «Оформить заказ». |
| **Оформление заказа** | Шаг 1 — адрес; Шаг 2 — способ оплаты; Шаг 3 — подтверждение; Шаг 4 — успех. Не более 4 шагов. |
| **Мои заказы**  | Список заказов (активные, доставленные), отслеживание. |
| **Чат**         | Список диалогов с продавцами; экран переписки (текст, фото). |
| **Профиль (личный)** | Аватар, имя, «Мои заказы», «Избранное», «Подписки на продавцов», настройки. |

### 2.3 Продавец

| Экран           | Описание |
|-----------------|----------|
| **Добавить товар** | Фото (несколько), название, цена, описание, категория. Минимум полей, крупные кнопки. |
| **Мой магазин** | То же, что «Профиль продавца», но с кнопками: «Добавить товар», «Сторис», «Статистика». |
| **Статистика**  | Просмотры товаров, охват, подписчики, переходы в профиль. |
| **Сторис**      | Запись сторис с товаром (фото/видео + ссылка на товар или текст). |
| **Сообщения**   | Входящие от покупателей (общий чат). |

### 2.4 Общие

- **Онбординг** — 3–4 экрана: «Листай как в соцсетях», «Покупай за 3 шага», «Веди магазин как профиль».
- **Регистрация/вход** — телефон или соцсети (Google, Apple).
- **Покупка в 1 клик** — на карточке товара кнопка «Купить сейчас» → адрес и способ оплаты по умолчанию → подтверждение (2 шага для постоянных пользователей).

## 3. UX для покупателя

### 3.1 Путь «Увидел — заинтересовался — купил»

1. **Обнаружение**  
   Листает ленту на главной или ищет через поиск/категории. Видит карточки с фото, ценой и кнопкой «Купить».

2. **Просмотр**  
   Тап по карточке → карточка товара. Свайп по фото, чтение описания, отзывов, профиль продавца. При желании — «В избранное» или «Написать продавцу».

3. **Решение купить**  
   «Купить» или «В корзину». Если «Купить сейчас» и настроен адрес/оплата — сразу шаг подтверждения.

4. **Оформление (3–4 шага)**  
   Адрес доставки → Способ оплаты → Проверка заказа → Подтверждение → Экран «Заказ оформлен».

5. **После покупки**  
   Статус в «Мои заказы», уведомления, при необходимости — чат с продавцом.

### 3.2 Принципы UX для покупателя

- **Минимум шагов** — не более 3–4 до «Заказ оформлен».
- **Одна главная кнопка** — «Купить» на карточке и на экране товара.
- **Быстрый скролл** — лента без лишних переходов, всё ключевое на карточке (фото, цена, кнопка).
- **Прозрачность** — цена, рейтинг продавца, отзывы и возможность написать продавцу видны сразу.
- **Избранное и подписки** — сохранять товары и следить за магазинами без перегрузки интерфейса.

## 4. UX для продавца

### 4.1 Профиль «как в Instagram»

- **Шапка профиля**: аватар, имя магазина, короткое описание (1–2 строки), кнопка «Подписаться».
- **Счётчики**: подписчики, товары (при желании — количество заказов).
- **Лента**: товары сеткой (2–3 колонки), каждая ячейка — обложка товара (фото + цена). Тап — открытие товара.
- **Сторис**: круг с обложкой над лентой; тап — просмотр сторис с товарами/акциями.

### 4.2 Публикация товара

Один экран (или два с прокруткой):

1. **Фото** — добавить 1–5 фото (первое — обложка).
2. **Название** — одна строка.
3. **Цена** — поле ввода.
4. **Описание** — текст (по желанию).
5. **Категория** — выбор из списка/чипов.
6. **Опубликовать** — одна кнопка.

Без лишних полей (артикулы, склады и т.д. — опционально или в настройках магазина позже).

### 4.3 Сторис и статистика

- **Сторис**: создать сторис (фото/видео), при желании привязать товар или текст (скидка, новинка). Показ 24 часа.
- **Статистика**: просмотры товаров, профиля, подписчики, переходы. Простые графики/цифры, без сложной аналитики на первом этапе.

### 4.4 Принципы UX для продавца

- Профиль воспринимается как «страница бренда», а не просто список объявлений.
- Публикация товара — за минуту, без длинных форм.
- Сторис и лента создают привычный соцсетевой контекст.
- Статистика даёт обратную связь без перегрузки.

## 5. Уникальные фишки маркетплейса «Базар»

### 5.1 Формат ленты

- **Лента как Reels/TikTok** — вертикальные карточки товаров, листание свайпом. Можно листать без перехода на отдельный экран.
- **Сторис сверху** — акции и новинки продавцов в формате сторис; тап по кругу — просмотр, тап по товару в сторис — переход к покупке.

### 5.2 Скорость покупки

- **Покупка в 1 клик** — для пользователей с сохранённым адресом и способом оплаты: «Купить» → подтверждение → готово (2 шага).
- **Жёсткий лимит 3–4 шага** для полного сценария: адрес → оплата → проверка → подтверждение.

### 5.3 Социальный слой

- **Подписка на продавцов** — лента может показывать «новое от тех, на кого подписан».
- **Профиль продавца как бренд** — не «объявление», а лента постов-товаров + сторис + описание и подписчики.
- **Чат с продавцом** — без перехода на внешние мессенджеры, всё внутри приложения.

### 5.4 Персонализация и вовлечение

- **Тренды дня** — блок на главной: популярные товары/категории за день.
- **Рекомендации** — на основе просмотров, избранного и подписок.
- **Популярная лента** — умная лента по интересам и поведению.

### 5.5 Визуал и анимации

- **Минималистичный UI** — много воздуха, акцент на фото товара и одну кнопку «Купить».
- **Плавные анимации** — переходы между экранами, появление карточек, лайк/избранное, переключение фото на карточке товара.
- **Карточки товаров** — крупное фото, цена, кнопка; при длинном нажатии или свайпе — быстрые действия (в избранное, поделиться).

### 5.6 Отличия от типичного маркетплейса

| Обычный маркетплейс | «Базар» |
|---------------------|--------|
| Список/сетка объявлений | Лента, которую листают как соцсети |
| Сложное оформление заказа | 3–4 шага, возможность «купить в 1 клик» |
| Продавец = объявление | Продавец = профиль с подписчиками и сторис |
| Много полей при публикации | Минимум: фото, цена, описание, категория |
| Нет сторис | Сторис с товарами и акциями |

## 6. Визуальный стиль (кратко)

- **Стиль**: современный минимализм, чистый UI.
- **Карточки**: скруглённые углы, тень или тонкая обводка, крупное фото, чёткая типографика цены и кнопки.
- **Цвета**: нейтральный фон (белый/светло-серый), акцентный цвет для кнопок и важных элементов (например, «Купить», иконка избранного).
- **Типографика**: один основной шрифт для текста, второй — для заголовков и цен.
- **Анимации**: плавные переходы (200–300 ms), микровзаимодействия при тапе (кнопки, избранное, лайк).

## 7. Краткая карта экранов (для прототипа)

```
Bottom Nav: [Главная] [Поиск] [+] [Избранное] [Профиль]

Главная → Лента товаров + сторис
        → Тап на карточку → Карточка товара → Купить → Оформление (3–4 шага)
        → Тап на продавца → Профиль продавца

Поиск   → Результаты + фильтры → Карточка товара

+       → Добавить товар (фото, цена, описание, категория) → Опубликовано

Избранное → Сетка сохранённых товаров → Карточка товара

Профиль → (Покупатель) Заказы, Избранное, Подписки, Настройки
        → (Продавец) Мой магазин, Статистика, Сторис, Сообщения
```
