# Как работает авторизация в tmr_tau

## Цепочка входа по логину и паролю

1. Ты вводишь **email** и **пароль** и нажимаешь **«Войти»**.
2. Приложение отправляет запрос в **Supabase Auth**: `signInWithPassword(email, password)`.
3. Если логин или пароль неверные — Supabase возвращает ошибку, приложение показывает сообщение внизу экрана (SnackBar).
4. Если Supabase принял вход — приложение берёт текущего пользователя и ищет его профиль в таблице **`users`**.
5. Если профиль найден — открывается главный экран. Если нет — приложение пытается создать строку в `users` и снова ищет профиль; если всё равно нет — собирает пользователя из сессии и всё равно пускает на главный экран.

---

## Почему не получается войти — частые причины

### 1. «Подтвердите email»
- В Supabase включено **Confirm email** (подтверждение почты).
- **Что сделать:** зайди в Supabase → **Authentication** → **Providers** → **Email** → выключи **Confirm email** и сохрани. После этого можно входить сразу после регистрации без перехода по ссылке из письма.

### 2. «Неверный email или пароль»
- Не совпадает пара email + пароль с тем, что использовалась при регистрации.
- **Что сделать:** проверь раскладку (английский/русский), пробелы, точный email. Если не помнишь пароль — зарегистрируй новый аккаунт с тем же или другим email.

### 3. «Нет аккаунта с таким email»
- Вход по email, с которым ещё никто не регистрировался.
- **Что сделать:** на экране входа нажми **«Нет аккаунта? Зарегистрироваться»**, введи email и пароль, зарегистрируйся. Потом войди с этими же email и паролем.

### 4. Ничего не происходит / остаётся экран входа
- Раньше такое могло быть, если в таблице `users` не было строки после входа. Сейчас приложение при успешном входе в Supabase либо подтягивает профиль из БД, либо создаёт его, либо пускает по данным сессии. Если проблема осталась — посмотри, не появляется ли внизу экрана сообщение об ошибке (SnackBar).

## Что проверить в Supabase

1. **Authentication → Providers → Email**  
   - **Confirm email** — лучше выключить для тестов, чтобы входить сразу после регистрации.

2. **Table Editor → users**  
   - После регистрации или первого входа должна появляться строка с твоим `id` (как у `auth.users`). Если таблицы `users` нет или в ней нет колонок `id`, `name`, `followers_count` — выполни скрипт **`supabase/schema.sql`** в SQL Editor.

3. **Authentication → Users**  
   - Там видны все зарегистрированные пользователи. Убедись, что пользователь с твоим email есть и статус не «unconfirmed», если у тебя включено подтверждение email.

---

## Порядок действий для проверки

1. В Supabase выключи **Confirm email** (Authentication → Providers → Email).
2. В приложении нажми **«Нет аккаунта? Зарегистрироваться»**, введи email и пароль (от 6 символов), зарегистрируйся.
3. После регистрации должен открыться главный экран. Если нет — нажми **«Уже есть аккаунт? Войти»** и войди с **теми же** email и паролем.
4. Если при входе внизу появляется сообщение — прочитай его: там будет одна из причин выше (подтверждение email, неверный пароль, нет аккаунта или другая ошибка).
