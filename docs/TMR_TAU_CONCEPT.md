# Концепция маркетплейса tmr_tau («Базар»)

## Видение

**tmr_tau** — маркетплейс с лентой как в Instagram/TikTok: покупатель листает товары и оформляет заказ за 3–4 шага; продавец ведёт профиль как бренд (лента товаров, сторис, подписчики).

---

## Структура приложения

- **Навигация (5 кнопок):** Главная → Поиск → Добавить товар → Избранное → Профиль
- **Модули:** Feed, Search, Product, Seller Profile, Checkout (3–4 шага), Messaging, Favorites

## Основные экраны

| Экран | Назначение |
|-------|------------|
| Главная | Лента товаров (свайп), сторис сверху, тренды дня, рекомендации |
| Поиск | Поле поиска, категории, фильтры, сетка результатов |
| Добавить товар | Фото, цена, описание, категория — минимум полей |
| Избранное | Сетка сохранённых товаров |
| Профиль | Личный кабинет / магазин: заказы, избранное, подписки, настройки |

## UX покупателя

- Листание ленты → тап по карточке → «Купить» или «В корзину» → оформление (адрес → оплата → подтверждение).
- Покупка в 1 клик при сохранённом адресе и способе оплаты.
- Избранное, отзывы, рейтинг продавца, чат с продавцом.

## UX продавца

- Профиль: аватар, описание, подписчики, лента товаров сеткой, сторис.
- Публикация: фото, цена, описание, категория — один экран.
- Статистика просмотров, возможность сторис с товарами.

## Уникальные фишки tmr_tau

- Лента в формате Reels/TikTok (вертикальный скролл карточек).
- Сторис продавцов на главной.
- Покупка в 1 клик, не более 3–4 шагов до «Заказ оформлен».
- Подписки на продавцов и лента «новое от подписок».
- Тренды дня и рекомендации по интересам.
- Минималистичный UI, плавные анимации, акцент на фото и кнопку «Купить».
