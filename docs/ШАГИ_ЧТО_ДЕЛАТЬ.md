## Шаг 1. Создать таблицы в Supabase

1. Открой в браузере: **https://supabase.com** → войди в свой проект (mukxbmcrwxqfbuhxoltd).
2. В левом меню нажми **SQL Editor**.
3. Нажми **New query**.
4. Открой в проекте файл **`supabase/schema.sql`** (в корне папки tmr_tau).
5. Скопируй **весь** текст из этого файла.
6. Вставь в окно запроса в Supabase.
7. Нажми **Run** (или Ctrl+Enter).
8. Внизу должно быть сообщение об успешном выполнении, без красных ошибок.

**Проверка:** в левом меню Supabase открой **Table Editor**. Должны быть таблицы: `users`, `products`, `orders`, `messages`, `favorites`, `followers`.

## Шаг 3. Добавить один тестовый товар вручную (через Supabase)

Чтобы на главной что-то отображалось:

1. В Supabase открой **Table Editor** → **users**.
2. Найди свою строку (твой email или имя). Скопируй значение в колонке **id** (это uuid, например `a1b2c3d4-...`). Это твой **seller_id**.
3. Открой таблицу **products**.
4. Нажми **Insert row** (или **Add row**).
5. Заполни:
   - **title:** например `Тестовый товар`
   - **description:** например `Описание`
   - **price:** например `1000`
   - **image_url:** пока оставь пустым или ``
   - **seller_id:** вставь скопированный id из шага 2
6. Сохрани строку.

**Проверка:** перезапусти приложение (в терминале нажми **R** или заново `flutter run`). На главной должна появиться карточка «Тестовый товар».

## Шаг 4. Проверить экран «Добавить товар» в приложении

1. В приложении открой вкладку **«Добавить»** (третья кнопка внизу).
2. Заполни: название, цену, описание (можно кратко).
3. Нажми **«Опубликовать»**.

**Проверка:** должно появиться сообщение «Товар добавлен». Сейчас товар в БД не сохраняется (это следующий шаг в коде), но экран и кнопка должны работать без ошибок.

## Шаг 6. Создать bucket для фото (когда будешь делать загрузку)

1. В Supabase: **Storage** в левом меню.
2. **New bucket** → имя: `products` → **Create bucket**.
3. В настройках bucket включи **Public** (чтобы по ссылке можно было показывать фото в приложении).
4. В **Policies** добавь политику: залогиненные пользователи могут загружать файлы (insert) в `products`.
